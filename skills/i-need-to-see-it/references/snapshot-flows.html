    Both flows start by freezing, while the guest flushes cached data to disk. Direct then keeps the guest frozen through the whole CSI snapshot. External keeps it frozen for one libvirt call. On Windows, VSS can keep a guest frozen for at most 10 seconds.

    How to ask for it

    Set snapshotMode: External on the VirtualMachineSnapshot. Without the field, snapshots keep using Direct.

    overlayScratchSize is optional and is accepted only with External mode. External mode is Alpha and needs the ExternalVMSnapshot feature gate.

    vmsnapshot.yaml
    apiVersion: snapshot.kubevirt.io/v1beta1
kind: VirtualMachineSnapshot
metadata:
  name: my-vm-snap
spec:
  source:
    apiGroup: kubevirt.io
    kind: VirtualMachine
    name: my-vm
  snapshotMode: External
  overlayScratchSize: 10Gi  # optional

    Follows the code on kubevirt/kubevirt main: pkg/storage/snapshot/external.go (virt-controller) and pkg/virt-launcher/virtwrap/storage/external_snapshot.go (virt-launcher). The design is VEP 321.
